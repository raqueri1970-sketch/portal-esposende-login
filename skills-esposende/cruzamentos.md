# Cruzamentos
Prioridade para chaves confiáveis: loja normalizada, CPF, documento/NF, código-base+numeração, fornecedor e identificadores de origem.
Cruzamentos padrão: Ajuste x Inventário (ajuste pós-inventário/reincidência); Ajuste x grade (outras numerações/último par); NF x Recebimento x Estoque; Comissão x campanha x pagamento; Compras x orçamento x realizado; Financeiro x fornecedor/documento/observação.
Nunca forçar junção por nome aproximado quando existir risco de homônimo. Se não houver chave segura, declarar dado insuficiente.
