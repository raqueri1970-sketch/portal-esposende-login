Politica de Privacidade - Portal Esposende

Esta politica descreve como o assistente "Portal Esposende" (Custom GPT) e sua integracao (Action) tratam os dados acessados.

Dados acessados

A integracao consulta dados resumidos e agregados de auditoria interna da Esposende (rede de calcados), como totais de notas fiscais canceladas, remanejo de mercadorias, almoxarifado, descontos e comissoes. Nao sao processados dados pessoais sensiveis de terceiros.

Uso dos dados

Os dados sao usados exclusivamente para responder as perguntas do usuario autorizado dentro da conversa do ChatGPT. Nenhum dado e armazenado, compartilhado ou usado para treinamento de modelos por esta integracao.

Armazenamento

Os dados residem em um banco de dados privado (Supabase) mantido pela empresa. A integracao apenas le esses dados no momento da pergunta; nao ha copia ou retencao adicional pelo GPT.

Contato

Duvidas sobre esta politica podem ser enviadas para o responsavel pelo Portal de Auditoria Esposende.
