# Segurança Patrimonial e CFTV (cópia publicada no Portal)

A fonte deste módulo é o repositório `sistema-de-auditoria`, pasta `seguranca-cftv/` (e `patrimonio-seguranca/`).
Esta cópia existe para o módulo abrir no mesmo endereço do Portal (github.io) e usar a mesma sessão de login.
Ao alterar lá, copie os arquivos `index.html`, `app.js`, `leitor.js` e `estilo.css` para cá e troque o `?v=`.
Nenhum dado fica no repositório: tudo vem do Supabase (tabelas `cftv_*`, acesso por perfil).
